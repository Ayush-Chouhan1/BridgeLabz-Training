## 📅 **Day 1 – CSV Data Handling with Java I/O**  
**(Date: 23-Jan-2026)**  
**Branch:** `java-iostreams-practice`

### Overview  
Today focused on **CSV data processing in Java**, covering reading, writing, validation, and large-file handling using both **core Java I/O** and **OpenCSV**.

### Topics Covered
- CSV fundamentals, structure, and real-world use cases
- Reading CSV files using:
  - `BufferedReader` (manual parsing)
  - OpenCSV (`CSVReader`)
- Writing CSV files using:
  - `BufferedWriter`
  - OpenCSV (`CSVWriter`)
- Parsing records using `String.split()`
- Mapping CSV rows to Java objects using `CsvToBean`
- Data validation techniques:
  - Numeric field validation
  - Regex-based column validation
- CSV operations:
  - Filtering
  - Searching
  - Updating records
  - Sorting data
  - Merging multiple CSV files
- Efficient processing of **large CSV files** using chunk-based reading
- Report generation and export from structured datasets
